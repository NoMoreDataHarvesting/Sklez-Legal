# Legal Documentation

Legal documents for **Skelzies** (bundle identifier `com.MirrorAI.Skelzies`), the
offline iPad skelly game.

## Live page

The privacy policy is published via GitHub Pages at:

**<https://nomoredataharvesting.github.io/Sklez-Legal/>**

That is the URL to enter in App Store Connect under *App Privacy → Privacy Policy
URL*.

## Files

| File | What it is |
|---|---|
| `index.html` | The published privacy policy page (GitHub Pages serves this from the repo root) |
| `PRIVACY.md` | The same policy in Markdown, readable directly on GitHub |
| `SKELZ README.md` | Reference copy of the app's developer README |

`index.html` and `PRIVACY.md` carry identical policy text. **If you change one,
change the other** — App Review may look at either.

## Publishing setup

GitHub Pages is configured as *Settings → Pages → Deploy from a branch → `main` /
`(root)`*. Pushing to `main` republishes the page within a minute or two.
